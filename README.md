# Kinsetsu Slot Study v0.1

個人研究用の試作Webアプリです。

## 実装したもの
- 3BET
- 3リール
- LEFT / CENTER / RIGHT 個別STOP
- 赤7 / 青7
- 12枚役 / 6枚役 / チェリー / REPLAY / POWER
- BIG 300 / REG 90
- POWERゲージ 0〜16
- ランダムBD TIMEルーレット 0〜5
- BD TIME中の低速リール＋当選確率アップ
- iPhone Safari / GitHub Pages向けレスポンシブUI
- CSS transform中心の軽量リール

## 注意
ゲームROM・公式スプライト・公式音源は含んでいません。
公開素材のコピーではなく、研究用に新規実装したUI/シンボルを使用しています。

## 起動
このフォルダの中身をGitHubリポジトリ直下にアップロードし、GitHub Pagesを有効化してください。
